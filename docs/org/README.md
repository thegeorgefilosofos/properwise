# Η ομάδα

Ο φάκελος αυτός είναι η κοινή γνώση δύο εργαλείων: του Grok, που διαβάζει τον
κόσμο έξω και του Claude Code, που γράφει κώδικα μέσα. Ο,τι δεν είναι γραμμένο
εδώ, το εφευρίσκουν — και η εφεύρεση βγαίνει πειστική, με σωστή μορφή και λάθος
αριθμό.

## Τι υπάρχει

| | |
|---|---|
| `briefing/` | Εξι τομείς. Ολη η γνώση του έργου, διαβασμένη από τον κώδικα. |
| `prompts/` | Δεκαοκτώ system prompts, ένα ανά ρόλο. |
| `SYNERGEIA.md` | Πώς ένα εύρημα του Grok γίνεται pull request χωρίς να σπάσει τίποτα. |
| `EREVNA-KAI-PARAGOGI.md` | Πώς δουλεύουν ΟΛΟΙ: πηγές, διασταύρωση, ΦΕΚ, prompts, περιεχόμενο. |
| `MINYMA-STON-CEO.md` | Το πρώτο μήνυμα προς τον συντονιστή, αυτοτελές. |
| `GROK-SYNDESI.md` | Τα έξι βήματα της σύνδεσης και τι κοστίζει. |

## Η σειρά για να στηθεί η ομάδα από το μηδέν

**1. Δώσε στον συντονιστή, με αυτή τη σειρά:**
`briefing/01-proion.md` → `02-istoriko.md` → `03-arxitektoniki.md` →
`04-sxediasi.md` → `05-glossa.md` → `06-kanones.md` → `SYNERGEIA.md` →
`prompts/00-syntonistis.md`.

**2. Ο συντονιστής μοιράζει ένα prompt σε κάθε ρόλο.** Μαζί με το prompt δίνει
τους τομείς που αφορούν τον καθένα (πίνακας παρακάτω) **και το
`EREVNA-KAI-PARAGOGI.md`, που το παίρνουν όλοι χωρίς εξαίρεση.** Ο ιδιοκτήτης
δεν μιλά με κανέναν άλλον.

**3. Συμπλήρωσε το όνομα.** Η δεύτερη γραμμή κάθε prompt λέει
`ΟΝΟΜΑ: [συμπληρώνεται]`. Κανένα δεν φέρει εφευρημένο ονοματεπώνυμο: τα bots
έχουν ήδη ονόματα και δεν τα δίνει ο κώδικας.

**4. Φτιάξε τις δύο ετικέτες** στο GitHub: `grok` και `claude`.

**5. Βάλε τις δύο ρυθμίσεις** που λέει το `SYNERGEIA.md` §6. Χωρίς αυτές η
γέφυρα μένει κλειστή, σιωπηλά και χωρίς σφάλμα.

## Οι επτά κανόνες

Είναι γραμμένοι αυτούσιοι μέσα σε καθένα από τα δεκαοκτώ prompts, στην ενότητα 5.
Δεν επαναλαμβάνονται εδώ γιατί δεν διαβάζονται από εδώ — διαβάζονται από εκεί.

Ο σκληρότερος και ο λόγος που υπάρχουν οι υπόλοιποι: **κανένα bot δεν γράφει σε
αρχείο που περιέχει ρυθμιζόμενη τιμή.** Μια λάθος τιμή εκεί δεν φαίνεται πουθενά:
βγαίνει σωστά μορφοποιημένη, σε έγγραφο με αριθμό και QR, με το όνομα του χρήστη
από πάνω και φεύγει στον λογιστή του.

## Τι επιβάλλεται από μηχανισμό, όχι από κείμενο

Μια οδηγία μέσα σε prompt δεν είναι μηχανισμός. Αυτά είναι:

| Μηχανισμός | Τι κάνει αδύνατο |
|---|---|
| `.github/workflows/grok-gefyra.yml` | ζήτημα χωρίς τα πέντε πεδία δεν εκτελείται· αλλαγή σε προστατευμένη διαδρομή κοκκινίζει |
| `scripts/guard-post-numbers.mjs` | λεζάντα με ψηφίο που δεν παρήγαγε ο κώδικας |
| `.claude/skills/` | τέσσερις επαναλαμβανόμενες δουλειές με τα βήματά τους γραμμένα |
| οι 126 φύλακες | κρίνουν και την τεκμηρίωση: ό,τι γράψει bot εδώ περνά από τους ίδιους ελέγχους |

## Ο κύκλος της μέρας

Μία αναφορά, 06:00, από τον συντονιστή. **Η σιωπή είναι έγκυρη αναφορά.**

Δεκαοκτώ αναφορές την ημέρα θα εκπαίδευαν τον παραλήπτη να μην τις διαβάζει —
το ίδιο επιχείρημα που γράφει το `scripts/marketing/posts.ts` για τον μετρητή
188 ημερών: δεν είναι επείγον, είναι θόρυβος.
