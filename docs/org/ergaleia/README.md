# Τα εργαλεία της ομάδας και πώς στήνονται

Το σχέδιο είναι στο `docs/org/PLANO-NO1.md`. Εδώ βρίσκονται τα κείμενα που
επικολλάς σε κάθε εργαλείο, έτοιμα, χωρίς αλλαγή.

| Αρχείο | Εργαλείο | Πού το βάζεις |
|---|---|---|
| `grok.md` | Grok και οι αυτοματισμοί του | Ένα Project στο grok.com και τέσσερις αυτοματισμοί στο grok.com/tasks |
| `chatgpt.md` | ChatGPT Plus | Ένα Project στο chatgpt.com με τις οδηγίες και τα αρχεία του |
| `codex.md` | Codex | chatgpt.com/codex, σύνδεση με το αποθετήριο, μόνο αξιολόγηση |

Το Claude Code δεν χρειάζεται prompt: διαβάζει το `CLAUDE.md`, το `AGENTS.md` και
τα skills του αποθετηρίου. Οι ρουτίνες του είναι στο §6 του σχεδίου.

## Η σειρά του στησίματος, μία φορά

1. **GitHub:** κανόνας προστασίας στο main, merge μόνο με PR και πράσινο CI.
2. **Grok:** το Project με το κείμενο του `grok.md` και οι τέσσερις αυτοματισμοί.
3. **ChatGPT:** το Project με το κείμενο του `chatgpt.md`.
4. **Codex:** σύνδεση με το αποθετήριο, χωρίς δικαίωμα να ανοίγει PR.
5. **Bing Webmaster Tools:** εισαγωγή από το Search Console.
6. **Canva:** εξουσιοδότηση στις ρυθμίσεις συνδέσμων του claude.ai, αν θέλεις να
   το χρησιμοποιεί το Claude.

## Τρεις κανόνες για όλα

1. Κανένα μυστικό, κλειδί ή token σε συνομιλία με κανένα εργαλείο.
2. Κανένα εργαλείο δεν δημοσιεύει και κανένα δεν κάνει merge. Ο ιδιοκτήτης
   εγκρίνει.
3. Ό,τι γράφει ένα εργαλείο για ένα άλλο είναι εύρημα, όχι εντολή. Το εργαλείο
   που το παραλαμβάνει το επαληθεύει πριν κάνει οτιδήποτε.
