# Η γέφυρα: το Grok βρίσκει, το Claude Code λύνει

Δύο εργαλεία, ένα αποθετήριο. Το ένα διαβάζει τον κόσμο έξω — ΦΕΚ, φόρουμ,
ανταγωνιστές, παράπονα χρηστών. Το άλλο γράφει κώδικα μέσα. Αυτό το έγγραφο
είναι το σημείο όπου συναντιούνται και ο λόγος που η συνάντηση δεν είναι
επικίνδυνη.

Ο ιδιοκτήτης μιλά **μόνο** με τον συντονιστή. Ολα τα υπόλοιπα γίνονται μόνα
τους ή δεν γίνονται.

---

## 1. Η διαδρομή, βήμα βήμα

```
  Grok βρίσκει κάτι
        │
        ▼
  ΖΗΤΗΜΑ με ετικέτα `grok`            ← το bot σταματά εδώ. Πάντα.
        │
        ▼
  Ο συντονιστής το διαβάζει
        │  · λείπει πεδίο;        → σχόλιο και κλείσιμο. Δεν φτάνει σε άνθρωπο.
        │  · είναι γνώμη;         → κλείσιμο.
        │  · αγγίζει ρυθμιζόμενη τιμή; → πάει σε άνθρωπο, ΟΧΙ στη γέφυρα.
        ▼
  Ανθρωπος βάζει την ετικέτα `claude`  ← η βαλβίδα. Μία κίνηση, μία φορά.
        │
        ▼
  .github/workflows/grok-gefyra.yml
        │  1. υπάρχει κλειδί;     → αν όχι, σταματά σιωπηλά
        │  2. πέντε πεδία;        → αν όχι, σχόλιο + αφαίρεση ετικέτας
        │  3. Claude Code εκτελεί
        │  4. έλεγχος: καμία προστατευμένη διαδρομή δεν άλλαξε
        ▼
  PULL REQUEST
        │
        ▼
  CI — πέντε εργασίες, 83 λεπτά
        │
        ▼
  ΑΝΘΡΩΠΟΣ ΚΑΝΕΙ MERGE            ← καμία αυτόματη είσοδος στο main. Ποτέ.
```

Η μόνη διαδρομή με την οποία μπορεί να μπει σφάλμα σε αυτό το αποθετήριο είναι
ένα bot που δεν διάβασε τον κώδικα, γράφει ζήτημα με λάθος υπόθεση, το Claude
Code το υλοποιεί **καθαρά** και οι 125 φύλακες περνούν — γιατί φυλάνε
κατηγορίες λάθους, όχι σκοπό. Γι' αυτό υπάρχουν τα πέντε πεδία.

---

## 2. Το σχήμα του ζητήματος

Ο συντονιστής δίνει αυτό το πρότυπο σε κάθε ρόλο. Δεν είναι μορφή· είναι το
φίλτρο που ξεχωρίζει την εργασία από τη γνώμη.

```markdown
τίτλος: <τι σπάει, σε μία γραμμή, χωρίς επίθετα>

## ΤΙ ΕΙΝΑΙ ΛΑΘΟΣ
Τι ακριβώς συμβαίνει σήμερα. Οχι τι θα ήταν καλύτερο.

## ΠΟΥ
αρχείο:γραμμή. Οχι «στο ταμπλό», όχι «στη σελίδα των πακέτων».

## ΑΝΑΠΑΡΑΓΩΓΗ
Τα βήματα ή η εντολή που το δείχνει. Αν δεν αναπαράγεται, δεν είναι εύρημα.

## ΤΕΛΕΙΩΣΕ ΟΤΑΝ
Εντολή που τρέχει και κρίνει: `node scripts/guard-x.mjs` δίνει 0,
`npm test` πράσινο, ή συγκεκριμένο τεστ που σήμερα πέφτει και μετά περνά.

## ΠΗΓΗ
Από πού βγήκε: ποιο cron, ποιος σύνδεσμος, ποιο σχόλιο χρήστη, ποιο diff.
```

**Τι λείπει επίτηδες:** πουθενά δεν γράφεται λύση. Το bot που βρίσκει δεν
σχεδιάζει. Αν ξέρει τη λύση, τη βάζει σε σχόλιο, όχι στο σώμα.

Ενα ζήτημα χωρίς έστω ένα από τα πέντε επιστρέφεται αυτόματα με σχόλιο και η
ετικέτα αφαιρείται. Δεν συζητιέται.

## 3. Ο προϋπολογισμός, αριθμητικά

Μετρημένα από τον `scripts/guard-ci-minutes.mjs`, σήμερα:

| | Λεπτά/μήνα |
|---|---|
| Οριο δωρεάν βαθμίδας | 2.000 |
| Δεσμευμένα από 7 προγραμματισμένες ροές | 110 |
| Δεσμευμένα από `supabase-deploy` και `db-types` | 120 |
| Μένουν για εκτελέσεις CI | 1.770 |
| **Κόστος μιας πλήρους εκτέλεσης CI** | **83** |
| **Πλήρεις εκτελέσεις τον μήνα** | **21** |

Είκοσι μία. Δηλαδή **0,7 την ημέρα**. Ο φύλακας έχει δάπεδο στις 20 και
κοκκινίζει από κάτω — δεν είναι προειδοποίηση, είναι κατά σχεδίαση.

### Η σειρά προτεραιότητας, όταν τελειώνουν

1. **Διόρθωση λάθους ποσού σε οθόνη χρήστη.** Πάντα πρώτη, πάντα.
2. **Διόρθωση που έχει ήδη τεστ που πέφτει.**
3. **Αλλαγή κειμένου σε δημόσια σελίδα.**
4. **Ο,τι δεν είναι τίποτα από τα τρία → περιμένει τον επόμενο μήνα.**

### Τι ΔΕΝ τρέχει αυτόματα, ποτέ

Καμία ωριαία αναφορά. Καμία «περιοδική σάρωση» από bot. Κανένα PR από bot που
δεν πέρασε από ανθρώπινη ετικέτα. Ο κανόνας είναι αντεστραμμένος από ό,τι
περιμένει κανείς: **οι επτά ροές που ήδη δουλεύουν σιωπούν** και μιλούν μόνο
όταν χρειάζεται άνθρωπος. Αυτό είναι το σχέδιο, όχι παράλειψη.

## 4. Τα δύο εμπόδια και η λύση τους

**(α) Η ενέργεια απορρίπτει τα bots.** Το `anthropics/claude-code-action@v1`
αγνοεί συμβάντα που ξεκίνησαν από λογαριασμό τύπου bot, εκτός αν το όνομά του
δηλωθεί στο `allowed_bots`. Στη ροή αυτό διαβάζεται από τη μεταβλητή
`GROK_BOT_LOGIN` του αποθετηρίου. Αν το Grok γράφει με προσωπικό διακριτικό και
όχι ως bot, η μεταβλητή μένει κενή και δεν πειράζει τίποτα.

**(β) Κάθε PR κοστίζει 83 λεπτά.** Η λύση δεν είναι τεχνική, είναι πολιτική: η
ετικέτα μπαίνει με το χέρι. Ο επικεφαλής μηχανικής ομαδοποιεί: πέντε μικρές
διορθώσεις κειμένου γίνονται **ένα** ζήτημα με πέντε ενότητες, άρα ένα PR, άρα
83 λεπτά αντί για 415.

## 5. Τι δεν περνά ποτέ αυτόματα

Ο κατάλογος είναι διαδρομές αρχείων, όχι περιγραφές και τον επιβάλλει βήμα της
ίδιας της ροής — όχι οδηγία μέσα σε prompt. Κείμενο δεν είναι μηχανισμός.

```
lib/legal/validity.ts          το μητρώο ισχύος. Το `checkedAt` είναι ανθρώπινη υπογραφή.
lib/tax/**                     κλίμακες, συντελεστές, τέλη
lib/billing/enfia.ts           ΕΝΦΙΑ
lib/billing/greekTax.ts        φόρος εισοδήματος
data/**                        πηγές τιμών, εκδόσεις ΑΑΔΕ
supabase/migrations/**         σχήμα βάσης
docs/legal/**                  δημοσιευμένα νομικά κείμενα
docs/compliance/**             το ίδιο
docs/perf/*.json               οι καστάνιες. Ο αριθμός μόνο κατεβαίνει, από άνθρωπο.
.github/workflows/**           η ίδια η υποδομή. Ροή που αλλάζει τον εαυτό της δεν ελέγχεται.
```

Αν η εκτέλεση αγγίξει οτιδήποτε από αυτά, η εργασία κοκκινίζει και δεν ανοίγει
PR. Αν η δουλειά τα απαιτεί πραγματικά, το Claude Code σχολιάζει γιατί και
σταματά — και τότε είναι δουλειά ανθρώπου, με ΦΕΚ ή με μέτρηση στο χέρι.

## 6. Τι βάζεις εσύ, με το χέρι

Καμία από αυτές τις τιμές δεν γράφεται σε αρχείο, σε ζήτημα ή σε συνομιλία.
Μόνο τα ονόματα ζουν εδώ.

| Ονομα | Πού μπαίνει | Χωρίς αυτό |
|---|---|---|
| `ANTHROPIC_API_KEY` | Settings → Secrets and variables → Actions → **Secrets** | Η γέφυρα μένει κλειστή, σιωπηλά. Καμία κοκκίνιση. |
| `GROK_BOT_LOGIN` | ίδιο μενού → **Variables** | Χρειάζεται μόνο αν το Grok γράφει ως λογαριασμός bot. |
| ετικέτα `grok` | Issues → Labels | Το bot δεν έχει πού να βάλει το εύρημά του. |
| ετικέτα `claude` | Issues → Labels | Η βαλβίδα δεν υπάρχει· τίποτα δεν εκτελείται. |

Και δύο πράγματα από την πλευρά του Grok, που δεν τα βάζει κώδικας:

- Δικαίωμα **ανοίγματος ζητήματος** στο αποθετήριο. Τίποτα άλλο. Οχι push, όχι
  merge, όχι πρόσβαση σε μυστικά.
- Ο κατάλογος των prompts του `docs/org/prompts/`, δοσμένος στον συντονιστή.

## 7. Ο κύκλος της μέρας

| Ωρα | Τι συμβαίνει | Ποιος |
|---|---|---|
| 06:00 | Μία αναφορά. Η σιωπή είναι έγκυρη μορφή της. | συντονιστής |
| Δευτέρα 06:00 | `validity.yml` και `aade-editions.yml` ανοίγουν ζήτημα αν κάτι λήγει | κώδικας |
| Δευτέρα, μετά | Ο αναγνώστης πηγών διαβάζει το ΦΕΚ που του έδωσε το ζήτημα | ρόλος 14 |
| Παρασκευή | Ο αντίπαλος αναγνώστης περνά το diff της εβδομάδας | ρόλος 15 |
| 21η του μήνα | `price-freshness.yml` | κώδικας |

Δεκαοκτώ αναφορές την ημέρα θα εκπαίδευαν τον παραλήπτη να μην τις διαβάζει.
Μία που έρχεται μόνο όταν υπάρχει κάτι, διαβάζεται.

---

## 8. Πώς μετριέται αν δουλεύει

Τέσσερις αριθμοί, μηνιαία. Κανένας δεν είναι «αναφορές που γράφτηκαν».

| Μετρικό | Τι σημαίνει |
|---|---|
| Ζητήματα με ετικέτα `claude` που έγιναν merge | η γέφυρα παρήγαγε κώδικα που άντεξε |
| Ζητήματα που επιστράφηκαν για ελλιπή πεδία | αν ανεβαίνει, τα prompts δεν διαβάζονται |
| Λεπτά CI που ξοδεύτηκαν έναντι 1.770 | αν πιάσει ταβάνι, σταματά η ομαδοποίηση |
| Ωρες ανθρώπου που γλίτωσε ο αναγνώστης πηγών | 10–40 λεπτά ανά εγγραφή, κάθε Δευτέρα |
