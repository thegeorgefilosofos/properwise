# Κίνηση: η τεχνική

Τα μοτίβα κώδικα πίσω από τους κανόνες του `SKILL.md`. Τα ελατήρια, το θόλωμα
αλλαγής, οι ακμές και ο δρομέας προσαρμόστηκαν από το `product-launch-motion`
(MIT, βλ. `proeleusi.md`). Η λήψη, η κωδικοποίηση και η ένταση είναι η συνταγή
του reel της Νέας Υόρκης και **δεν αλλάζουν χωρίς νέα μέτρηση**.

## Το συμβόλαιο: καθαρός χρόνος

Η σελίδα ορίζει μία συνάρτηση, `window.render(t)`, όπως η μηχανή του
`scripts/marketing/shorts/engine.ts`. Κάθε στυλ κάθε στοιχείου είναι συνάρτηση του
`t` και μόνο. Αναζήτηση στο ίδιο `t` δίνει τα ίδια εικονοστοιχεία, άρα ο έλεγχος
ανά χτύπο και η παράλληλη απόδοση είναι δυνατά.

Στρώσεις: `#bg` (το ναυτικό φόντο), `#device` (ο φορητός, πάντα ολόκληρος),
`#screen` (η διεπαφή μέσα στην οθόνη, εδώ ζει η «κάμερα»), `#hud` (δρομείς,
ετικέτες σε συντεταγμένες οθόνης).

Τα χρώματα: φόρτωσε το ίδιο το `app/globals.css` στη σελίδα, με το `public/` ως
ρίζα του τοπικού διακομιστή ώστε τα `/fonts/*.woff2` να βρίσκονται. Η σελίδα
γράφει μόνο `var(--mkt-*)` και τα tokens της εφαρμογής. Ο έλεγχος:

```
grep -n -E '#[0-9a-fA-F]{3,8}\b' <φάκελος>/film.html; echo "κωδικός: $?"
```

Κωδικός 1 (τίποτα δεν βρέθηκε) είναι το σωστό.

## Ελατήρια

```js
// Κλειστής μορφής απόκριση βαθμίδας με απόσβεση, από 0 σε 1.
function stepR(tau, { w, z }) {
  if (tau <= 0) return 0;
  if (z >= 1) { const x = w * tau; return 1 - Math.exp(-x) * (1 + x); }
  const wd = w * Math.sqrt(1 - z * z);
  return 1 - Math.exp(-z * w * tau) * (Math.cos(wd * tau) + (z * w / wd) * Math.sin(wd * tau));
}
// Τιμή που αλλάζει στόχο πολλές φορές: άθροισμα ενός ελατηρίου ανά αλλαγή.
class Track {
  constructor(v0) { this.v0 = v0; this.cur = v0; this.ev = []; }
  to(t, v, sp) { if (v !== this.cur) { this.ev.push([t, v - this.cur, sp]); this.cur = v; } return this; }
  at(t) { let v = this.v0; for (const [ti, d, sp] of this.ev) v += d * stepR(t - ti, sp); return v; }
}
```

Απόσβεση 0,72 έως 0,9 για σχήματα, 1,0 για κάμερα και κείμενο. Η ζουμ της
κάμερας κινείται σε λογαριθμική κλίμακα (`Math.exp(track.at(t))`): γραμμικό ζουμ
μοιάζει να επιταχύνει. Για βρόχο, πρόσθεσε και τις περιόδους k = −1, −2.

## Ακέραια εικονοστοιχεία

Η λήψη γίνεται με `deviceScaleFactor: 3` πάνω σε θύρα προβολής ίση με το τελικό
μέγεθος σε CSS px. Ενα CSS px είναι λοιπόν ένα εικονοστοιχείο του τελικού
καρέ. Κάθε μετατόπιση περνά από στρογγύλευση:

```js
const px = (v) => Math.round(v);
el.style.transform = `translate(${px(x)}px, ${px(y)}px)`;
```

Η κλίμακα της κάμερας αλλάζει μόνο μέσα σε βύθιση. Οταν φαίνεται κείμενο, η
κλίμακα είναι σταθερή και η μετατόπιση ακέραια.

## Η βύθιση 8 καρέ

```js
const FPS = 30, HALF = 4 / FPS;            // 4 καρέ κάτω, 4 πάνω
// Ορατότητα κειμένου γύρω από κάθε αλλαγή κατάστασης T.
function dip(t, T) {
  const d = Math.abs(t - T);
  if (d >= HALF) return { o: 1, b: 0 };
  const x = d / HALF;                       // 0 στο κέντρο, 1 στις άκρες
  return { o: x, b: (1 - x) * 6 };          // αδιαφάνεια και θόλωμα σε px
}
```

Το παλιό κείμενο ζει ώς το `T`, το νέο από το `T`. Η μεταμόρφωση του σχήματος
(πλάτος, ύψος, ακτίνα, χρώμα από tokens) και κάθε αλλαγή κάδρου τρέχουν στο
`[T − HALF, T + HALF]` και τελειώνουν με ελατήριο. Οτι δεν προλαβαίνει να
καθίσει στα 4 καρέ συνεχίζει **χωρίς κείμενο από πάνω**: το νέο κείμενο
περιμένει.

## Δρομέας

- Βέλος σε `--mkt-text-primary` με περίγραμμα `--mkt-bg-base`. Ετικέτα «Εσύ». Ο
  δρομέας της Νόας σε `--mkt-accent` με ετικέτα «Νόα». Χωρίς διαβαθμίσεις.
- Κλίση με την ταχύτητα: `clamp(-vx * 0.0045, ±14°)`. Η ετικέτα ακολουθεί με
  καθυστέρηση `-v * 0.012` px, περιορισμένη.
- Πάτημα: κλίμακα `1 − 0.16 * exp(-((t − tc) / 0.045)²)` και κύμα 0,4″ σε
  `--accent-border`.
- Σύρσιμο: όσο κρατιέται, η τιμή υπολογίζεται από τη θέση του δρομέα. Μόλις
  αφεθεί, γυρίζει με ελατήριο από όπου ήταν.
- Ο δρομέας κινείται και πάνω από κείμενο: είναι το μόνο κινούμενο στοιχείο που
  επιτρέπεται εκεί, επειδή δεν είναι κείμενο. Ποτέ δεν σέρνει κείμενο μαζί του.

## Μετρητής ποσού

Λωρίδες ψηφίων 0 έως 9 σε θέσεις με το πλάτος του τελικού ψηφίου, αποκοπή μόνο
κάθετα. Ψηφίο θέσης p: `floor(v / 10^p) % 10 + max(0, (v % 10^p) − (10^p − 1))`,
ώστε να κινείται μόνο όταν κρατά το από κάτω. Η τελική τιμή είναι **ακριβώς** η
τιμή που επέστρεψε η συνάρτηση του `lib/tax/**` ή του `lib/billing/**`.
Υποδιαστολή κόμμα και το € κολλητά. Ο μετρητής κυλά μέσα σε βύθιση ή σε πλαίσιο
χωρίς άλλο κείμενο γύρω του και κάθεται πριν εμφανιστεί η ετικέτα του.

## Ηχος

- **Συντεθειμένος:** `scripts/marketing/synth.ts`. Το BPM και η αρχή του πρώτου
  μέτρου τα ορίζεις εσύ, άρα το πλέγμα είναι γνωστό ακριβώς: `beat = 60 / bpm`.
- **Κομμάτι ελεύθερο δικαιωμάτων:** άδεια ελεγμένη **ανά κομμάτι** (βιβλιοθήκες
  που λέγονται ελεύθερες ανακατεύουν κομμάτια με περιορισμούς). Αποθήκευσε τη
  σελίδα της άδειας μαζί με το αρχείο. Το πλέγμα μετριέται: φασματική ροή και
  αυτοσυσχέτιση για τον ρυθμό, κορυφές στη ζώνη του τυμπάνου για τη θέση.
  Οποιο σενάριο Python διαβάζει κατεβασμένο αρχείο τρέχει με `python3 -I`.
- Κάθε ήχος μετακινείται ώστε **η δική του κορυφή** να πέφτει στον χτύπο.
- Οι χρόνοι των ήχων εξάγονται από την ίδια την ταινία (μία πηγή αλήθειας), όχι
  από δεύτερη λίστα.

## Λήψη

Playwright Chromium, θύρα προβολής 1080×1920 (ή 1080×1350), `deviceScaleFactor: 3`.
Πριν από κάθε καρέ: `await page.evaluate(t => window.render(t), t)` και
`await page.evaluate(() => document.fonts.ready)`.

Θόλωμα κίνησης μόνο για σχήμα και δρομέα: 4 υποκαρέ γύρω από τον χρόνο του καρέ,
`subT(i) = floor(i / 4) / 30 + ((i % 4) − 1.5) / 120`. Καρέ όπου τίποτα δεν
κινείται τραβιέται μία φορά και αντιγράφεται στα 4 υποκαρέ: το αποτέλεσμα είναι
ίδιο και η λήψη τέσσερις φορές φθηνότερη.

Ανθεκτικότητα: ξαναδοκίμασε το υποκαρέ σε νέα σελίδα αν αποτύχει, ξανάνοιξε τον
περιηγητή αν αποσυνδεθεί, `process.exit(0)` στο τέλος. Αποδίδεις σε κομμάτια και
σβήνεις τα PNG κάθε κομματιού μόλις κωδικοποιηθεί.

## Κωδικοποίηση (η συνταγή, ακριβώς)

```
ffmpeg -y -framerate 120 -i sub/%06d.png -i mix.wav \
  -vf "gblur=sigma=0.5,scale=1080:1920:flags=lanczos,tmix=frames=4:weights='1 1 1 1',select='eq(mod(n\,4)\,3)',setpts=N/(30*TB),format=yuv420p" \
  -r 30 -c:v libx264 -crf 12 -preset slow -tune stillimage -profile:v high -level 4.2 \
  -x264-params keyint=300:min-keyint=30:scenecut=40:deblock=-2,-2:aq-mode=3:psy-rd=1.0,0 \
  -colorspace bt709 -color_primaries bt709 -color_trc bt709 -color_range tv \
  -c:a aac -b:a 192k -movflags +faststart out-9x16.mp4
```

Το θόλωμα σ0,5 εφαρμόζεται **στην ανάλυση λήψης (3×)**, πριν από τη σμίκρυνση
lanczos. Για το 4:5, `scale=1080:1350` και ξεχωριστή απόδοση με δική της
διάταξη: ποτέ αποκοπή από το 9:16, γιατί η συσκευή πρέπει να μένει ολόκληρη.

Για αρχείο ανεβάσματος με όριο μεγέθους, ξεκίνα από το ίδιο MP4 με δύο περάσματα
και τις ίδιες παραμέτρους x264. Μην αλλάξεις το `-tune` ή το `deblock`.

## Ενταση

Δύο περάσματα `loudnorm` στο μίγμα, πριν από τη σύνδεση με την εικόνα:

```
ffmpeg -i mix-raw.wav -af loudnorm=I=-14:TP=-1.5:LRA=11:print_format=json -f null -
ffmpeg -i mix-raw.wav -af loudnorm=I=-14:TP=-1.5:LRA=11:measured_I=…:measured_TP=…:measured_LRA=…:measured_thresh=…:linear=true -ar 48000 mix.wav
```

Επαλήθευση στο τελικό MP4:

```
ffmpeg -i out-9x16.mp4 -af ebur128=peak=true -f null - 2> loud.txt; echo "κωδικός: $?"
```

Δεκτό: ολοκληρωμένη −14 LUFS (±0,5), αληθινή κορυφή κάτω από −1 dBTP. Το
`gateAudio` του `scripts/marketing/shorts/qa.ts` κάνει τον ίδιο έλεγχο κορυφής.

## Ελεγχος

- Ενα καρέ ανά χτύπο σε φύλλο επαφής, πριν από την πλήρη απόδοση.
- Τα περάσματα στις άκρες κάθε βύθισης (`T − HALF`, `T`, `T + HALF`) από το
  χρονολόγιο.
- Μετά την απόδοση, από το MP4:

```
ffmpeg -i out-9x16.mp4 -vf "fps=1,scale=270:-1,tile=6x4" sheet.png
ffprobe -v error -count_frames -select_streams v:0 -show_entries stream=nb_read_frames -of csv=p=0 out-9x16.mp4
ffmpeg -i out-9x16.mp4 -vf "select='gt(scene,0.25)',showinfo" -f null - 2> seams.txt
```

  Το πλήθος καρέ ίσο με διάρκεια επί 30. Κάθε μεγάλη αλλαγή στο `seams.txt`
  πρέπει να είναι σκοπούμενο χτύπημα.
- Στο 9:16, ό,τι διαβάζεται μένει μέσα στις ζώνες των πλατφορμών (y 250 έως 1536
  και έξω από τα δεξιά 140px του κάτω μισού). Ο έλεγχος «Ζώνες YouTube /
  Instagram / TikTok» του `qa.ts` είναι ο ίδιος κανόνας.

## Εξώφυλλο

Το πιο δυνατό **καθισμένο** καρέ (κείμενο μέσα, όχι σε βύθιση) γίνεται `cover.jpg`
και μπαίνει στη θέση του καρέ 0, χωρίς να προστεθεί καρέ, ώστε κάθε πλατφόρμα να
δείχνει αυτό ως μικρογραφία:

```
ffmpeg -y -i out.mp4 -i cover.jpg -filter_complex "[0:v][1:v]overlay=0:0:enable='eq(n,0)'[v]" \
  -map "[v]" -map 0:a? -c:v libx264 -crf 12 -preset slow -tune stillimage -profile:v high -level 4.2 \
  -x264-params keyint=300:min-keyint=30:scenecut=40:deblock=-2,-2:aq-mode=3:psy-rd=1.0,0 \
  -c:a copy -movflags +faststart out.poster.mp4
```
