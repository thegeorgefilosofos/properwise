# Νέα δημόσια σελίδα

Δύο σφάλματα έχουν ήδη γίνει με νέες σελίδες και τα δύο πέρασαν καθαρά από build
και δοκιμές:

- **Βάρος.** Κάθε `page.tsx` είναι δική του συνάρτηση στο Vercel, με ~2,5 MB
  κοινού κώδικα μέσα. Οι δεκαεννέα αγγλικές σελίδες ανέβασαν το βάρος ανά
  ανάπτυξη από 180 σε 233 MB (02/11/2026). Λύθηκε με έναν διανομέα,
  `app/en/[[...slug]]/page.tsx`.
- **Υπόσχεση που δεν τηρείται.** Σελίδα στον χάρτη που γύριζε 307 στη σύνδεση:
  είπαμε στη Google να την ευρετηριάσει και δεν άνοιγε.

## Πριν γράψεις κώδικα

1. **Υπάρχει ήδη ερώτημα με πρόθεση;** Ονόμασε το ερώτημα («υπολογισμός ΕΝΦΙΑ
   2027») και τη σελίδα που απαντά σήμερα. Αν απαντά ήδη μία, βελτιώνεις
   εκείνη· δεύτερη σελίδα για το ίδιο ερώτημα τρώει την πρώτη.
2. **Τι είναι μοναδικό εδώ;** Υπολογισμός, πηγή, παράδειγμα σε ευρώ. Σελίδα που
   διαφέρει από άλλη μόνο σε μία λέξη (πόλη, έτος, όνομα) είναι doorway page.
3. **Μέτρησε το περιθώριο:** `npm run build` και μετά `node scripts/server-weight.mjs`.
   Το όριο είναι το `total` του `docs/perf/server.json` επί 1,08, περίπου
   189,9 MB. Στις 17/11/2026 το χτίσιμο ζύγιζε 179,4 MB: χωρούν το πολύ τέσσερις
   νέες συναρτήσεις και καμία δεν χρειάζεται.

## Πού μπαίνει

| Σελίδα | Μπαίνει | Οχι |
|---|---|---|
| αγγλική εκδοχή | `view.tsx` στον φάκελό της, δηλωμένη στον διανομέα `app/en/[[...slug]]` | νέο `page.tsx` κάτω από `app/en/` |
| σελίδα χωρίς δικό της διανομέα | επαναγραφή στο `rewrites()` του `next.config.ts` προς υπάρχοντα διανομέα, όπως το `/xartis` → `/en/_xartis` | νέα συνάρτηση για σελίδα κειμένου |
| ελληνικός οδηγός | εγγραφή στο `app/odigos/guides.ts`· σήμερα κάθε οδηγός είναι δικός του φάκελος με `page.tsx`, άρα δική του συνάρτηση: μετράς το βάρος πριν και μετά | οδηγός χωρίς εγγραφή στο `guides.ts` (δεν φτάνει σε κόμβο, χάρτη, `/llms.txt`) |
| κάρτα κοινοποίησης | `app/og/share.ts`, από τη μία διαδρομή `/og/[slug]` | `opengraph-image.tsx` ανά σελίδα |

Αν η σελίδα πραγματικά θέλει δική της συνάρτηση, γράφεις στο PR τη μέτρηση πριν και μετά. Το skill `kastania` λέει πώς ανεβαίνει όριο. Χωρίς μέτρηση δεν
ανεβαίνει.

## Η σελίδα, με τη σειρά

1. **Μεταδεδομένα** από το `publicMetadata()` (`app/publicMetadata.ts`): τίτλος
   απόλυτος με ` · PROPERWISE` στο τέλος, περιγραφή 70 έως 160 χαρακτήρες,
   canonical, hreflang και OG από μία κλήση. Χωρίς αυτό η σελίδα κληρονομεί το
   `canonical: "/"` της ρίζας και λέει ότι είναι η αρχική.
2. **Ζεύγος γλώσσας** στο `PAGE_PAIRS` του `lib/i18n/paths.ts`, αν υπάρχει
   αγγλική. Το hreflang και το `x-default` βγαίνουν από εκεί.
3. **Κατάλογος.** Η σελίδα μπαίνει στην πηγή που διαβάζει ο κατάλογος
   (`PUBLIC_TOOLS`, `LISTED_GUIDES`, ή όνομα στο `NAMED` του
   `app/siteCatalogCore.ts`· οι κόμβοι θεμάτων στο `app/thema/hubs.ts` όταν
   συγχωνευθεί το #594). Από εκεί φτάνει μόνη της σε `sitemap.xml`, `/llms.txt`
   και `/xartis`. **Καμία** δεύτερη λίστα.
4. **Δημόσια πρόσβαση** στο `PUBLIC` του `proxy.ts`. Ο `guard-public-routes`
   κόβει σελίδα του χάρτη που ζητά σύνδεση.
5. **Σχήμα** με `organizationNode()` και `ORG_REF`, `breadcrumbJsonLd()` από το
   `lib/seo/breadcrumbs.ts`. Κανένας νέος κόμβος οργανισμού.
6. **Αριθμοί** από `lib/tax/**`, `lib/billing/**`, με πηγή από το
   `lib/legal/validity.ts`. Ούτε στον τίτλο ούτε στην περιγραφή ψηφίο γραμμένο
   στο χέρι.
7. **Σύνδεσμοι** από τον γονικό κόμβο και από τουλάχιστον μία σελίδα του ίδιου
   θέματος, με κείμενο που λέει τι θα βρεις.
8. **Ημερομηνία ενημέρωσης** με `npm run tools:stamp` ή `npm run guides:stamp`.
9. **Δεδομένα χρήστη;** Τότε δεν είναι δημόσια σελίδα: `NOINDEX` από το
   `lib/seo/noindex.ts` και διαδρομή στο `NOINDEX_PATHS`, εκτός καταλόγου.

## Επαλήθευση

Χωρίς σωλήνα, το καθένα μόνο του:

```
npm run guards
npm test
npx tsc --noEmit
npm run lint
npm run build
node scripts/server-weight.mjs
```

Και στο HTML του χτισίματος: ένα `<title>`, ένα canonical προς τον εαυτό της,
hreflang και στις δύο πλευρές, ένα `<h1>`, JSON-LD με τον ίδιο `@id` οργανισμού.
